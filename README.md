# Managing Partner

Desktop app for macOS.

Download it at [managingpartner.fr/download](https://www.managingpartner.fr/download).

- Apple Silicon (M1 and later): `ManagingPartner-darwin-arm64.dmg`
- Intel: `ManagingPartner-darwin-x64.dmg`

First launch: if macOS blocks the app, open System Settings, then Privacy & Security, and click Open Anyway.
